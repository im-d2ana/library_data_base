# Библиотека — информационная система

Учебный проект по дисциплине «Базы данных»: приложение на Python (Tkinter) поверх PostgreSQL.
Полный путь от анализа предметной области и инфологической модели до даталогической схемы, форм, запросов, отчёта и тестирования.

## Возможности

**Библиотекарь:** 

- просмотр и поиск экземпляров фонда,
- добавление и удаление (мягкое) экземпляров,
- оформление читательских билетов, 
- оформление и редактирование комплектов выдачи, 
- просмотр списков читателей и выдач.

**Читатель:** 

- каталог,
- поиск по названию / автору / жанру / издательству,
- история выдач, 
- отчёт о прочитанных экземплярах за период.

## Схема данных

11 таблиц, связи «многие ко многим» (экземпляр — автор, выдача — библиотекарь) вынесены в отдельные таблицы. 
Книга (произведение) отделена от экземпляра (физической копии), справочники (тип, жанр, издательство) вынесены отдельно.

Что реализовано на уровне БД и приложения:
- внешние ключи и `CHECK`-ограничения (возраст 7–100, допустимые статусы, формат дат);
- мягкое удаление экземпляров (`deleted`), чтобы не терять историю выдач;
- проверки бизнес-правил (нельзя выдать или удалить уже выданный экземпляр);
- параметризованные запросы (`%s`), без подстановки строк.

## Стек

Python 3.13 · Tkinter · PostgreSQL · psycopg2
